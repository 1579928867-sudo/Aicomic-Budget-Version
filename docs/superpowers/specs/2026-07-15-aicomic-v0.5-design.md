# AI 漫剧 v0.5 设计规格

**日期**: 2026-07-15
**状态**: 已确认
**从**: v0.4 (5-step pipeline: Screenwriter → CharDesigner → SceneDesigner → ShotVisualizer → VideoGenerator)

---

## 目标

v0.4 → v0.5，三项独立增强：

1. **View 图描述填充** — 增强现有 Char/Scene Designer 的 LLM prompt，一次调用产出多角度 prompt 并回填 DB
2. **Video Composer Agent** — 新增 Agent，用 MoviePy 拼接 video_clip + 字幕 + 转场 → final_video
3. **DoubaoVideoGenerator Playwright 真接入** — 用 Playwright 浏览器自动化替换 Mock，实现真实视频生成

实现顺序：1 → 2 → 3（按依赖关系最小排列，3 可独立并行）

---

## 任务 1：View 图描述填充

### 策略

增强现有 Agent 的 LLM system prompt，在原有 JSON 输出中增加多角度 view prompt 字段，一次 LLM 调用同时产出主体描述 + 多角度 prompt。

### Char Designer 改动

**文件**: `src/aicomic/agents/char_designer.py`

**System prompt 变更** — 在 variants 输出格式中新增三个字段：

```json
{
  "variant_name": "default",
  "front_view_prompt": "...",
  "side_view_prompt": "...",
  "back_view_prompt": "..."
}
```

字段要求：
- `front_view_prompt`：正面全身站立，保留核心视觉元素，"正面特写，人物居中，纯白背景"
- `side_view_prompt`：侧面全身，"侧面全身展示身体侧轮廓和服装侧面细节，纯白背景"
- `back_view_prompt`：背面全身，"背面全身，展示背面发型和服装背面设计，纯白背景"
- 三视图统一保持 `写实电影感风格` + 纯白背景，与现有 char design 一致

**`_build_appearance_json()` 改动** — 在 appearance dict 中增加三个 key：
```python
"front_view_prompt": variant.get("front_view_prompt", ""),
"side_view_prompt": variant.get("side_view_prompt", ""),
"back_view_prompt": variant.get("back_view_prompt", ""),
```

**`execute()` 改动** — 在每个 variant 写入 DB 后，调用新方法回填 view 列：
```python
db.update_appearance_variant_views(
    variant_id=variant_id,
    front=variant.get("front_view_prompt", ""),
    side=variant.get("side_view_prompt", ""),
    back=variant.get("back_view_prompt", ""),
)
```

### Scene Designer 改动

**文件**: `src/aicomic/agents/scene_designer.py`

**System prompt 变更** — 在 scenes 输出格式中新增三个字段：

```json
{
  "name": "萧澈卧室",
  "wide_view_prompt": "古代仙侠风格，写实电影感风格，横向16:9...",
  "mid_view_prompt": "古代仙侠风格，写实电影感风格，横向16:9...",
  "close_view_prompt": "古代仙侠风格，写实电影感风格，横向16:9..."
}
```

字段要求：
- `wide_view_prompt`：广角全景，展示整个场景空间关系，"全景展示场景全貌"
- `mid_view_prompt`：中景，展示核心活动区域，"中景展示场景核心区域"
- `close_view_prompt`：特写，展示关键道具/纹理/材质细节，"特写展示场景关键细节"
- 场景多视图保持 `无人纯场景 no humans` + `写实电影感风格` + `横向16:9`

**`execute()` 改动** — `update_scene_card()` 调用时传入 6 个字段（原 3 个 + 3 个 view）

### DB 改动

**文件**: `src/aicomic/db/repository.py`

1. 新增方法 `update_appearance_variant_views(variant_id, front, side, back)`：
   ```python
   def update_appearance_variant_views(self, variant_id: int, front: str, side: str, back: str):
       self.conn.execute(
           "UPDATE appearance_variant SET front_view=?, side_view=?, back_view=? WHERE id=?",
           (front, side, back, variant_id),
       )
       self.conn.commit()
   ```

2. 扩展 `update_scene_card()` 签名：
   ```python
   def update_scene_card(self, scene_id, description, lighting, style,
                         wide_view="", mid_view="", close_view=""):
   ```
   SQL 改为同时更新 6 个字段。

**注意**：`appearance_variant` 的 `front_view`/`side_view`/`back_view` 列和 `scene_card` 的 `wide_view`/`mid_view`/`close_view` 列已存在于 v0.4 schema 中，无需 migration。

### 测试

- `tests/test_char_designer.py`：Mock LLM 返回的 variant fixture 增加 view prompt 字段；断言这些字段出现在 `appearance_json` 中和 DB 列中
- `tests/test_scene_designer.py`：Mock LLM 返回的 scene fixture 增加 view prompt 字段；断言 DB 的 view 列被正确填充

## 任务 2：Video Composer Agent（新增）

### 定位

Pipeline 第 6 步，仅当 `--with-video` 时在 VideoGenerator 之后运行。

### 架构

```
VideoComposerAgent.execute()
  ├── 加载 video_clips（db.get_video_clips(script_id)，按 shot_num 排序）
  ├── 加载 storyboard_shots（获取 narration/dialogue 用于字幕文本）
  ├── Compose（MoviePy）：
  │   ├── 1. concatenate_videoclips([clip1, clip2, ...])
  │   ├── 2. 每个 clip 叠加字幕层（CompositeVideoClip）
  │   │      - 旁白字幕：底部、小字、白色文字 + 半透明黑底、全程持续
  │   │      - 对话字幕：底部居中、中字、白色 + 黑边描边、角色名前缀
  │   ├── 3. 片段间 crossfade 转场（可选，默认 0.5s）
  │   └── 4. 输出到 data/videos/final_{chapter_id}.mp4
  └── 写入 final_video 表
```

### 字幕规则

| 类型 | 字号 | 位置 | 样式 | 持续时间 |
|------|------|------|------|---------|
| narration | 小 (24px) | 底部偏上 | 白字 + 半透明黑底条 | 整个 shot |
| dialogue | 中 (32px) | 底部居中 | 白字 + 黑边描边，格式 "角色名：台词" | 整个 shot |
| 两者共存 | narration 上，dialogue 下 | narration 在 dialogue 上方 | — | 各自持续 |

### 转场

- 片段之间 0.5s crossfade（`clip.crossfadeout(0.5)` / MoviePy 2.x `crossfade`）
- 片头 fade in 0.5s，片尾 fade out 0.5s
- 无对话/旁白的 shot 不做额外处理，单纯拼接

### 容错

- 缺失的 clip 文件跳过（log WARNING），不阻塞整体拼接
- 所有 clip 缺失 → raise 明确错误
- MoviePy 渲染失败 → 捕获异常，log ERROR，返回失败但不阻塞 pipeline

## 任务 3：DoubaoVideoGenerator Playwright 真接入

### 认证方式

Cookie-based 浏览器自动化：
1. 用户首次手动在浏览器登录豆包/即梦
2. 导出 cookie 到 `data/doubao_cookies.json`（标准 Netscape JSON 格式）
3. 启动时加载 → 注入 Playwright `BrowserContext`
4. Cookie 过期时检测响应 → 抛出 `CookieExpiredError`

### 实现架构

```
DoubaoVideoGenerator(VideoGenerator)
  ├── __init__(cookie_file, headless, output_dir, timeout, poll_interval, selectors)
  │   ├── 加载 cookie 文件
  │   └── 初始化 Playwright（lazy，延迟到首次 generate）
  ├── _ensure_browser() → 启动/复用 chromium browser context
  ├── generate(prompt, duration_sec) → VideoResult
  │   ├── 1. 导航到即梦视频生成页
  │   ├── 2. 等待 prompt 输入框可见
  │   ├── 3. 填入 prompt（逐字输入或 fill）
  │   ├── 4. 点击"生成"按钮
  │   ├── 5. 轮询检测生成状态（每 poll_interval 秒检查）
  │   │      - 检测完成状态 → 获取视频 URL
  │   │      - 检测失败状态 → 返回失败
  │   │      - 超时 → 抛出 TimeoutError
  │   ├── 6. 下载视频 → output_dir / clip_{uuid}.mp4
  │   └── 7. 构造 VideoResult
  ├── close() → 关闭 browser
  └── 容错：单个 shot 失败不阻塞；cookie 过期明确报错；重试 1 次
```

### 选择器策略

选择器外置到 `config/settings.yaml`，方便 UI 变更时只改配置不碰代码：

```yaml
doubao:
  cookie_file: "data/doubao_cookies.json"
  headless: true
  timeout_sec: 300
  poll_interval_sec: 3
  output_dir: "data/videos"
  video_page_url: "https://jimeng.jianying.com/ai-tool/video/generate"  # 待验证
  selectors:
    prompt_input: "textarea[placeholder*='描述']"
    generate_button: "button:has-text('生成')"
    generating_indicator: "[class*='generating']"
    status_done: "[class*='success']"
    status_failed: "[class*='error']"
    video_result: "video"
    download_button: "[class*='download']"
```

Code 层读取 selectors，优先用 `data-testid`/`aria-label`，fallback 到 CSS class。如果配置中 selector 为 null 或不提供，code 中有硬编码 fallback。

### Cookie 格式

`data/doubao_cookies.json` — 标准 Playwright cookie 数组：
```json
[
  {"name": "sessionid", "value": "...", "domain": ".bytedance.com", "path": "/"},
  ...
]
```

提供脚本 `scripts/export_cookies.py` 供用户用 Playwright 自动导出 cookie（打开浏览器 → 用户手动登录 → 自动保存 cookie 到文件）。

### 容错与降级

| 场景 | 处理 |
|------|------|
| 单个 shot 生成失败 | WARNING 日志，继续下一 shot（现有 VideoGeneratorAgent 逻辑已支持） |
| Cookie 过期 | 检测页面跳转到登录页 / 401 → 抛 `CookieExpiredError`，附带重新导出指引 |
| Playwright 选择器超时 | 重试 1 次；仍失败 → 跳过该 shot |
| Browser crash | 下次 generate 时自动重启 browser |
| 下载超时 | 60s 超时，失败 → 跳过 |

### 改动文件

| 文件 | 改动 |
|------|------|
| `doubao/client.py` | `DoubaoVideoGenerator.generate()` 实现 Playwright 全流程；新增 `_ensure_browser()`、`_inject_cookies()`、`_poll_status()`、`_download_video()` 等私有方法；新增 `close()`；新增 `CookieExpiredError` |
| `config/settings.yaml` | 新增 `doubao` 段（选择器 + 超时 + URL 配置） |
| `main.py` | `--video-backend {mock,doubao}` 参数；`doubao` 时实例化 `DoubaoVideoGenerator` |
| `requirements.txt` | 新增 `playwright` |

### 测试

- Cookie 加载逻辑单元测试（mock JSON 文件读取）
- `name` 属性返回 `"doubao"`
- `generate()` mock Playwright page 测试完整流程（monkeypatch `_ensure_browser` 返回 mock page）
- 端到端测试标记 `@pytest.mark.skip`（需要真实 cookie + 网络 + 豆包额度，仅手动运行）

## Pipeline 最终形态 (v0.5)

```
Screenwriter → CharDesigner → SceneDesigner → ShotVisualizer → VideoGenerator → VideoComposer
                                                                  ├── Mock (默认)
                                                                  └── Doubao (--video-backend doubao)
```

CLI：
```bash
# 纯文本 pipeline (不生成视频)
python -m aicomic run chapter.txt

# 含 mock 视频 + 拼接
python -m aicomic run chapter.txt --with-video

# 含真实豆包视频 + 拼接
python -m aicomic run chapter.txt --with-video --video-backend doubao
```
