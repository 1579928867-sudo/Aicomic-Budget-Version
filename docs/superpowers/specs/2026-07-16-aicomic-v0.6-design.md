# AI 漫剧 v0.6 设计规格

**日期**: 2026-07-16
**状态**: 设计中
**从**: v0.5 (6-step pipeline: Screenwriter → CharDesigner → SceneDesigner → ShotVisualizer → VideoGenerator → VideoComposer)

---

## 目标

v0.5 → v0.6，核心主题：**补齐真实生成能力**。用 Playwright 浏览器自动化统一驱动豆包网页版，实现真实的角色/场景图片生成和视频生成。

三项工作：
1. **DoubaoBrowserClient** — 统一的 Playwright 浏览器客户端，封装生图+生视频
2. **ImageGeneratorAgent** — 新增 pipeline 步骤，为角色 variant 和 scene card 生成真实图片
3. **VideoGenerator 改造** — 将现有 DoubaoVideoGenerator 底层切到同一 browser client，校准选择器

---

## 任务 1：DoubaoBrowserClient — 统一浏览器客户端

### 定位

所有豆包网页版操作的底层引擎。管理 Playwright 浏览器生命周期，对上暴露 `generate_image()` 和 `generate_video()` 两个接口。

### 文件

- **新建**: `src/aicomic/doubao/browser.py`

### 接口

```python
from dataclasses import dataclass
from pathlib import Path

@dataclass
class ImageResult:
    success: bool
    file_path: str          # 本地保存路径
    url: str                # 原始 URL
    metadata: dict          # {width, height, aspect_ratio, ...}

@dataclass
class VideoResult:
    success: bool
    file_path: str
    duration_sec: float
    metadata: dict

class DoubaoBrowserClient:
    def __init__(
        self,
        cookie_file: Path = Path("data/doubao_cookies.json"),
        headless: bool = True,
        output_dir: str = "data/",
        timeout_sec: int = 300,
        poll_interval_sec: int = 3,
        rate_limit_sec: int = 10,
        selectors: dict | None = None,
    ): ...

    def ensure_browser(self) -> None: ...
    def close(self) -> None: ...
    def generate_image(self, prompt: str, aspect_ratio: str = "16:9") -> ImageResult: ...
    def generate_video(self, prompt: str, duration_sec: float = 5.0) -> VideoResult: ...
```

### 浏览器生命周期

```
_ensure_browser()
  ├── 首次调用 → 启动 Playwright Chromium
  │   ├── launch(headless=...)
  │   ├── new_context()
  │   ├── add_cookies(从 JSON 文件加载)
  │   └── 保持 browser + context 复用
  ├── 后续调用 → 直接复用已有 browser
  └── 崩溃 → 下次调用自动重启

close()
  ├── context.close()
  ├── browser.close()
  └── playwright.stop()
```

### 生图流程

```
generate_image(prompt, aspect_ratio="16:9"):
  1. ensure_browser()
  2. page = context.new_page()
  3. page.goto(image_page_url)
  
  4. 等待 prompt 输入框 → page.fill(textarea, prompt)
  5. 选择宽高比 → page.click(ratio_button)
  6. 点击生成 → page.click(generate_btn)
  
  7. 等待生成完成（两种检测方式）：
     a. 优先：监听 SSE/WebSocket 流（页面 JS 拦截 fetch）
     b. 备选：轮询 DOM 查结果图片是否出现
  
  8. 提取图片 URL → requests.get(url) → 保存到 data/images/{uuid}.png
  9. page.close()
  10. 返回 ImageResult
  
  速率限制：每两次调用之间自动 sleep(rate_limit_sec)
```

### 生视频流程

```
generate_video(prompt, duration_sec=5.0):
  (与生图类似，导航到视频生成页面)
  1-3. 同上
  4. fill(prompt)
  5. click("生成")
  6. 轮询状态直到完成（超时则返回失败）
  7. download → data/videos/{uuid}.mp4
  8. 返回 VideoResult
```

### 选择器配置（从 config/settings.yaml 读取）

```yaml
doubao:
  cookie_file: "data/doubao_cookies.json"
  headless: true
  timeout_sec: 300
  poll_interval_sec: 3
  rate_limit_sec: 10
  output_dir: "data/"
  
  pages:
    image: "https://www.doubao.com/chat/create-image"
    video: "https://www.doubao.com/chat/create-video"
  
  selectors:
    image:
      prompt_input: "textarea[placeholder*='描述']"
      generate_btn: "button:has-text('生成')"
      result_img: "img[class*='result']"
      loading: "[class*='generating']"
      ratio_1_1: "[data-ratio='1:1']"
      ratio_16_9: "[data-ratio='16:9']"
      ratio_9_16: "[data-ratio='9:16']"
    video:
      prompt_input: "textarea[placeholder*='描述']"
      generate_btn: "button:has-text('生成')"
      result_video: "video"
      status_done: "[class*='success']"
      status_failed: "[class*='error']"
```

> ⚠️ 选择器是占位值。实现阶段第一步用 Playwright 打开豆包页面实测确认。

### 容错

| 场景 | 处理 |
|------|------|
| Cookie 过期（页面跳转到登录） | 抛 `CookieExpiredError`，提示重新导出 |
| 单个生图/生视频失败 | 返回 `ImageResult/VideoResult(success=False)` |
| 浏览器崩溃 | `_browser = None`，下次调用自动 `ensure_browser()` |
| 下载超时 | 60s 超时，返回失败 |
| 并发限制触发 | 逐张串行，间隔 `rate_limit_sec` |

## 任务 2：ImageGeneratorAgent — 新增图片生成 Agent

### 定位

Pipeline Step 3.5，在 SceneDesigner 之后、ShotVisualizer 之前运行。用 `DoubaoBrowserClient` 为每个角色 variant 和场景 card 生成真实图片。

### 文件

- **新建**: `src/aicomic/agents/image_generator.py`
- **新建**: `tests/test_image_generator.py`

### 接口

```python
class ImageGeneratorAgent(AgentInterface):
    agent_name = "image-generator"

    def __init__(self, browser_client: DoubaoBrowserClient): ...

    def validate_input(self, input_data: dict[str, Any]) -> bool:
        return ("chapter_id" in input_data and "script_id" in input_data)

    def execute(self, input_data: dict[str, Any], db: Database) -> AgentResult:
        # Input:  {"chapter_id": int, "script_id": int}
        # Output: {"images_generated": int, "variants_processed": int, "scenes_processed": int}
```

### 执行流程

```
execute({chapter_id, script_id}):
  1. 幂等检查 → db.get_agent_status("image-generator", chapter_id) == "done" → 跳过
  
  2. 标记 running → log started
  
  3. 加载角色 variants：
     SELECT * FROM appearance_variant av
     JOIN character_card cc ON av.character_id = cc.id
     WHERE cc.chapter_id = ?
     → 过滤出有 view prompt 但缺图片的 variant
  
  4. 为每个 variant 生成图片（逐张串行）：
     for variant in variants:
       for view in ["front", "side", "back"]:
         prompt = variant[f"{view}_view_prompt"]
         result = browser.generate_image(prompt, aspect_ratio="16:9")
         if result.success:
           db.update_appearance_variant_image(variant_id, view, result.file_path)
           images_generated += 1
         sleep(rate_limit_sec)  # 避免触发并发限制
  
  5. 加载场景 cards：
     SELECT * FROM scene_card WHERE chapter_id = ?
     → 过滤出有 view prompt 但缺图片的 scene
  
  6. 为每个场景生成图片（逐张串行）：
     for scene in scenes:
       for view in ["wide", "mid", "close"]:
         prompt = scene[f"{view}_view_prompt"]
         result = browser.generate_image(prompt, aspect_ratio="16:9")
         if result.success:
           db.update_scene_card_image(scene_id, view, result.file_path)
           images_generated += 1
  
  7. 标记 done → log completed → 返回 AgentResult
```

### 容错

- 单个图片生成失败 → log WARNING，继续下一张
- 所有图片都失败 → 返回 success=False，不阻塞下游
- 浏览器崩溃 → 自动重启继续

## 任务 3：VideoGenerator 改造

### 定位

将现有 `DoubaoVideoGenerator`（在 `doubao/client.py` 中）底层切到 `DoubaoBrowserClient`，消除重复的 Playwright 代码。

### 改动

- `DoubaoVideoGenerator` 的 `generate()` 方法改为调用 `self.browser.generate_video(prompt, duration_sec)`
- 构造函数接受一个已初始化的 `DoubaoBrowserClient` 实例（共享）
- 不再自己管理 Playwright 生命周期

### 修改文件

- **修改**: `src/aicomic/doubao/client.py` — 简化 `DoubaoVideoGenerator.generate()`
- **修改**: `src/aicomic/main.py` — 实例化一个 `DoubaoBrowserClient`，共享给 `ImageGeneratorAgent` 和 `VideoGeneratorAgent`

`scene_card` 增加 3 个图片路径列：

```sql
ALTER TABLE scene_card ADD COLUMN wide_image TEXT DEFAULT '';
ALTER TABLE scene_card ADD COLUMN mid_image TEXT DEFAULT '';
ALTER TABLE scene_card ADD COLUMN close_image TEXT DEFAULT '';
```

通过 `migrate_schema()` 自动迁移。

### 新增方法

`repository.py`:

```python
def update_appearance_variant_image(self, variant_id: int, view: str, file_path: str) -> None:
    """回填 appearance_variant 的 {view}_image 列."""
    column = f"{view}_image"
    self.conn.execute(
        f"UPDATE appearance_variant SET {column} = ? WHERE id = ?",
        (file_path, variant_id),
    )
    self.conn.commit()

def update_scene_card_image(self, scene_id: int, view: str, file_path: str) -> None:
    """回填 scene_card 的 {view}_image 列."""
    column = f"{view}_image"
    self.conn.execute(
        f"UPDATE scene_card SET {column} = ? WHERE id = ?",
        (file_path, scene_id),
    )
    self.conn.commit()
```

## 任务 5：Orchestrator + CLI 集成

### Orchestrator

`run_chapter()` 新增 `with_images: bool = False` 参数。

在 Step 3 (SceneDesigner) 和 Step 4 (ShotVisualizer) 之间插入：

```python
# ── Step 3.5: Image Generator (optional) ──
img_result = None
if with_images and script_id:
    img_result = self.bus.run(
        "image-generator",
        {"chapter_id": chapter_id, "script_id": script_id},
        self.db,
    )
```

### CLI

```bash
# 纯文本 pipeline（不生成图片不生成视频）
python -m aicomic run chapter.txt

# 含图片生成
python -m aicomic run chapter.txt --with-images

# 含视频（mock）
python -m aicomic run chapter.txt --with-video

# 含图片 + 真实豆包视频
python -m aicomic run chapter.txt --with-images --with-video --video-backend doubao
```

新增 `--with-images` 参数（`action="store_true"`）。

在 cmd_run 中，`DoubaoBrowserClient` 只实例化一次，共享给 ImageGenerator 和 DoubaoVideoGenerator。
